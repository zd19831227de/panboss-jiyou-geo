# GEO 项目资源目录

`geo/` 是GEO 的项目级调用资源目录，和代码、数据库、前后端一起构成完整项目。

后续封装、迁移、交付、备份时必须包含整个 `geo/` 目录；缺少该目录时，系统不能标记为完整可交付版本。

## 目录约定

- `knowledge_base/`：品牌事实、证据源、问题矩阵、引用诊断等知识库资源。
- `source_maps/`：行业信源图谱和平台选择规则。

## 调用边界

- 运行时代码只能通过稳定路径读取 `geo/` 下资源，不能依赖开发机外部目录。
- `geo/` 下资源不得保存密码、token、cookie、浏览器 profile 或 `.env`。
- 可验证证据文件仍按现有证据目录保存；`geo/` 只保存可迁移的知识、规则、索引和清单。
