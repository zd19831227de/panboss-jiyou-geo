# GEO 知识库

本目录保存随项目封装的 GEO 运营知识库资源。

知识库是项目不可分割的调用资源，不放在用户主目录、临时目录或外部 Hermes 全局知识库中。

## 资源类型

- `brand_facts`：品牌事实、项目事实、服务事实。
- `evidence_sources`：官网、平台页、地图、百科、媒体、监管、资质等可验证来源。
- `question_matrix`：推荐、对比、避坑、交易、口碑、政策、售前问答。
- `citation_diagnostics`：未抓取、未索引、知识缺口、平台错配、内容可信度不足、竞品压制、AI 未引用等归因。

## 封装要求

后续桌面壳、安装包、迁移包必须把 `geo/knowledge_base/` 原样带上。没有知识库资源时，只能算代码包，不能算完整 GEO 项目包。
